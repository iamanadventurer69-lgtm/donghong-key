# 东鸿密钥｜点亮每一度电

面向浙江东鸿电子股份有限公司内部员工的企业文化探索 MVP。**原生微信小程序**，WXML / WXSS / JavaScript + Canvas 2D，不含 H5、WebView、游戏引擎或远程依赖。运行小程序无需 npm 安装或后端服务。

## 快速运行

1. 安装并打开[微信开发者工具（稳定版）](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 选择「导入项目」，选择本 README 所在的 `donghong-key` 文件夹，确保目录内有 `project.config.json`。
3. 使用自己的小程序 AppID；只做本地体验可选择工具提供的测试号/游客模式。仓库默认 `appid: touristappid`，若当前工具不接受这个占位值，在导入窗口改选测试号或输入自己的 AppID。
4. 开发模式选「小程序」，后端服务不启用云服务，点击「编译」。代码目录由配置指向 `miniprogram/`。
5. 初始页面为首页。点击「开启文化探索」，依次完成序章和第一章。
6. 真机预览时请使用有权限的真实 AppID，点击开发者工具「预览」后扫码。游客模式的真机能力受工具限制。

项目建议基础库 3.7.0 或以上，使用默认 WebView 渲染模式。所有视觉和模块均本地绘制，不需要配置网络域名、下载素材或构建 npm。

## 已实现

- **首页**：能源网络 Canvas、使命、探索进度、章节状态、愿景、理念与四项价值观。
- **序章**：三段能源故事，显性使命导入，领取使命密钥。
- **第一章「技术之芯」**：文化导入 → 四模块交互拆解 → 拖拽或点选组装 → 精度异常识别 → 校准与模拟复测 → 新场景方案选择。
- **文化强化页**：创新、精进印记，回顾行为与文化的对应关系，选择工作行动承诺并完成章节。
- **探索档案**：本机进度、最近保存时间、节点完成状态、文化体系、清档确认、保存失败重试。
- **自动存档**：每个有效操作同步保存到本地 storage；未完成文化强化之前不会显示为 100%。

第二、三章仅显示「后续篇章」，没有伪造可进入的入口。当前进度百分比仅指第一阶段。预计体验约 5–8 分钟，实际时长需员工试用验证；完整 20–30 分钟体验留待后续篇章。

## 第一章试玩路径

1. 阅读三段序章，领取使命密钥。
2. 第一章文化导入后，点击四个产品模块查看职责。
3. 拖动模块到对应槽位，或点一下模块，再点槽位：
   - 采样单元 → 信号入口
   - 计量核心 → 数据计算
   - 通讯模块 → 数据出口
   - 电源模块 → 稳定供电
4. 找出测试点 B：偏差 +2.4%，超出本关教学阈值 ±0.5%。
5. 选择「追溯采样与计量链路，再校准复测」。
6. 为光伏场景选择「组合双向计量与通讯能力，并验证数据」。
7. 进入文化印记，选择一项工作行动，点击保存，完成第一章。

错误选择会解释后果，允许重试，不设失败惩罚或排行榜。模块放到槽位外会归位，不计错误。

## 内容与产品边界

企业文化原文来自本次需求。价值观解释、剧情及行动承诺为教学文案，建议由企业文化负责人审阅。

电表外观、模块、电路连接、精度数据、阈值与校准结果都是**简化教学模拟**，不是东鸿真实型号的硬件图、规格、认证参数或维修指导。当前没有引入未核实的成立年份、知识产权数量、认证范围和销售国家数量。Canvas 的网络点亮是剧情效果，不表示其他章节已经开发完成。

## 项目结构

```text
project.config.json       微信开发者工具导入配置
miniprogram/
  app.js / app.json / app.wxss
  data/content.js         企业文化、剧情、模块、测试数据、选项与强化文案
  utils/state.js          关卡状态、前置条件、存档清洗、进度与续玩路由
  utils/storage.js        本地存档、内存降级与保存失败提示
  components/energy-network/  Canvas 2D 能源网络组件
  pages/home/             首页
  pages/prologue/         序章
  pages/chapter/          第一章的五个步骤
  pages/culture/          文化强化与行动承诺
  pages/progress/         进度与文化档案
tests/                   无额外依赖的逻辑、页面控制器与静态检查
```

新增文案、模块说明、测试记录优先修改 `data/content.js`。增加新的游戏规则时同步修改 `utils/state.js` 和相应页面。Canvas 和拖拽均按容器尺寸/屏幕坐标计算；拖拽提供点选替代操作。

## 存档规则

存储键：`donghong.culture.mvp.v1`。包含序章位置、当前步骤、已认识/已装配模块、异常识别、复测、创新挑战、行动承诺、重试计数与更新时间。没有姓名、手机号、微信身份或服务器上传。

完成关键动作后立即同步保存，不依赖退出事件。读写失败时显示提示，本次会话保留内存进度，并可到探索档案重试保存。清理微信缓存、更换设备或卸载后不能恢复。版本不兼容或损坏的字段安全回退，不通过残缺存档解锁后续。

## 自动化检查

安装 Node.js 18+ 后，在项目文件夹运行：

```sh
npm test
npm run check
```

测试覆盖完整关卡流程、错误反馈、前置条件、存档恢复、保存失败、点选组装、拖放边界与页面跳转。页面测试使用微信 API 模拟，不等同于微信运行时或真机验收。静态检查验证 JS、JSON、页面文件完整性及事件绑定。

具体测试结果及手动验收项见 `VALIDATION.md`。

## 动态互动更新

能源网络加入沿线光点和核心脉冲；组装成功吸附点亮、错误槽位抖动；精度测试页新增可通断电的实时实验台，负载滑杆联动功率读数与 Canvas 波形；文化印记加入点亮入场效果。Canvas 动画在页面隐藏或组件卸载时停止。波形和功率为教学演示，与精度题固定数据独立。

重新打开原项目后点击编译即可更新。已有进度不会清除；要体验第一章全部流程，可在探索档案中选择重新探索。

## 固定窗口与天蓝主题更新

所有页面禁用纵向滚动，使用固定视窗分屏。左右滑动空白区域翻页，也可点击底部箭头；上下滑动不会触发翻页。首页 3 屏、序章 3 屏、第一章 7 屏、文化印记 3 屏、探索档案 4 屏。

第一章依次为文化导入、模块认识、组装、动态实验台、精度排查、校准复测、创新挑战。未完成当前任务时不会跳过关卡；向右滑动回看不撤销进度。拖拽区和实验台单独处理触摸，不触发外层翻页。序章前后翻页保存当前故事位置；其他页面回到小程序时根据已保存任务恢复，普通介绍页页码不单独存档。

界面、导航栏、Canvas 电路、波形和动效统一使用天蓝色与白色，并针对较矮视窗压缩间距。原项目目录点击「编译」即可更新；如之前使用解压出的副本，请重新下载新版 ZIP。存档格式未变，无需清空进度。

16 项自动化测试通过，全部 7 个 WXML 模板与 WXSS 编译通过，20 个分屏模板渲染通过。上述检查不替代模拟器与真机的排版验收。
